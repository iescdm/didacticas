Carpeta de una aplicación

Una carpeta con su index.html, esté donde esté en tu disco.

Enlace web

Una dirección de internet, por ejemplo una página ya publicada.

Cada subcarpeta con un index.html es una aplicación. Si no lo tiene, se listan sus archivos .html. Con el lápiz cambias el nombre de una aplicación y le asignas un grupo; los grupos aparecen como pestañas. Con «Cambiar archivo» eliges qué archivo .html de esa carpeta abre cada aplicación. Quitar una aplicación solo la saca de esta lista: no borra ningún archivo. Si cambias el nombre de una carpeta o de un archivo, pulsa «Actualizar lista»: se conservan las destacadas, las quitadas, los grupos y los nombres que hayas puesto. Mantén esta pestaña abierta mientras usas las que abras desde aquí; si recargas una aplicación con F5, vuelve a lanzarla desde esta lista.
