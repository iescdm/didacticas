    Antes de conectar: DHCP y DNS
    
        
    
          
          
        
    
      
    
      
    Antes de pedir una página, un cliente necesita dos cosas: una dirección IP, que le da el servidor DHCP, y saber qué IP corresponde al nombre que escribió, que le dice el servidor DNS. Son servicios del sistema como los demás. Detén uno y vuelve a reproducir para ver dónde se rompe.
    
      
    
        
    
        
    
          
    
          
          
          
    
          
    
        
    
      
    
    
    
    
    
      
    Una conexión, paso a paso
    
        
    
          
          
        
    
      
    
      
    Así se establece una conexión TCP con el servicio que elegiste en «Clientes y servidores». El cliente y el servidor se saludan en tres pasos (SYN, SYN-ACK, ACK) antes de enviar datos.
    
      
    
      
    
    
    
    
    
      
    ¿Cambia el puerto cuando se establece la conexión?
    
        
    
          
          
        
    
      
    
      
    No. El servidor escucha en un puerto y todas las conexiones que acepta siguen usando ese mismo puerto. Lo que cambia es el puerto del cliente: cada conexión usa uno temporal distinto, y por eso el servidor sabe distinguirlas.

    Instalar un sistema operativo por multicast
    
        
    
          
          
        
    
      
    
      
    Para instalar el mismo sistema en muchos equipos a la vez, cada uno arranca por la red (PXE): consigue una IP por DHCP, descarga un cargador pequeño por TFTP y recibe la imagen del sistema por multicast. El servidor emite la imagen una sola vez y todos los equipos que se han unido al grupo la reciben a la vez, en lugar de enviársela a cada uno por separado. Apaga un servidor y vuelve a reproducir para ver dónde se rompe.
