Cómo usar la app

Muestra cómo pasa el código de la flash y el disco a la RAM y la CPU en Windows y Linux.

  • Opciones (desplegable de la derecha): elige el sistema, el firmware y la vista.
  • Vista teórica: tarjetas de flash, disco, RAM y CPU. El punto azul muestra de dónde a dónde pasa el código.
  • Vista terminal: comandos reales con salida de ejemplo, para comprobar cada fase desde el sistema ya arrancado. Marca «Mostrar detalle» (también disponible en la vista arranque) para añadir el título de cada fase y las notas aclaratorias; sin marcar, solo salen los comandos y su salida.
  • Vista arranque: el texto y las pantallas que verías mientras el equipo arranca. Con «Mostrar detalle» se añaden también los títulos de fase, las notas y las salidas que solo aparecen en algunos casos.
  • Navegar: Anterior, Siguiente y Reproducir, o las teclas ← → y la barra espaciadora. Las barras de colores saltan a cualquier paso.
  • Fase actual: el primer apartado de esta ayuda explica qué ocurre en la fase («n de N») y sus siglas. Cambia solo al avanzar de paso, y puedes seguir navegando con el panel abierto.
  • Mover y redimensionar la ayuda: arrastra su cabecera para moverla y sus bordes derecho e inferior (o la esquina inferior derecha) para cambiar el tamaño. Con el teclado: enfoca la cabecera con Tab y usa las flechas para moverla, o Mayús + flechas para cambiar el tamaño.
  • Se recuerda tu configuración: el sistema, el firmware, la vista, «Mostrar detalle», el paso en el que estabas y la posición, el tamaño y los apartados abiertos de la ayuda se guardan en este navegador y se restauran al volver a abrir el archivo. «Restablecer valores», en el desplegable de opciones, lo borra.
  • Esc cierra este panel y el desplegable.
Notas sobre lo que se muestra
  • Vista terminal: muestra comandos reales con salida de ejemplo, abreviada y con valores inventados. En las fases de firmware no existe terminal, así que se muestra cómo consultar ese resultado una vez arrancado el sistema.
  • Vista arranque: muestra texto típico de un equipo concreto (aquí, una placa AMI y Ubuntu Server 24.04, sin "quiet splash"), abreviado. Varía según el fabricante, la distribución y las opciones de arranque.
  • Pantallas gráficas: el logotipo del fabricante, el arranque de Windows y el inicio de sesión se dibujan como pantallas simuladas, con una marca ficticia, y no como texto de consola. Windows casi no escribe texto al arrancar: casi todo su arranque son esas pantallas.
  • Simplificación del esquema: en un arranque real el MBR se mueve de 0x7C00 antes de cargar el VBR.
